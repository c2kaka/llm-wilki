# Indigo Live 0427: 校准 (Recalibration)
Indigo 2026-04-27 月末直播文字整理。核心主题：AI 急速进化中人类需要校准的方向——认知（chat → agent）、定位（中间地带消失）、组织（CEO 直接调度 Agent）、投资（碳基 → 硅基）、人类自身（判断力与品味）。

## Key Points
- 中间地带正在消失：百倍速人类 vs 低端自动化之间是死亡之谷
- 全球 81 亿人中仅 0.3% 用过付费 AI 产品，0.04% 用 AI 写过代码
- Dario Amodei：AI 水平从高中生到大学生，金融/咨询/科技/编程入门级白领将在 1-5 年内被替代
- Anthropic Economic Index：22-25 岁年轻人入职高暴露职业比例同比下降 14%
- Karpathy 职业暴露度评分：美国约 6000 万岗位在高暴露区，对应 3.7 万亿美元年薪
- 模型公司从卖 Token 到卖工作：OpenAI + Anthropic ARR 超 450 亿美金，超过 Adobe + Salesforce + ServiceNow + Workday 总和
- Coding App 是浏览器之外的下一代杀手级应用：Claude Code 6 个月增长 70 倍
- Rewired Index 五层架构：物理层 → 数字基础层 → 核心智能层 → 应用层
- MCP 是 agentic computer 的开源操作系统（Jensen Huang）
- Mini AGI 组织形态：CEO 直接调度 Agent，人类回到系统边缘
- 人类核心能力：判断力、品味、学习的欲望
- Rick Rubin："I have no technical ability... The confidence that I have in my taste"
