# MCP (Model Context Protocol)
开放的 AI 工具接入标准，被 Jensen Huang 称为"agentic computer 的开源操作系统"。MCP 是 Agent 时代的连接协议。

## Details
Jensen Huang 在 GTC 上的论述：
- Windows 让个人电脑成为可能
- Linux 让服务器成为可能
- HTML 让 Web 成为可能
- Kubernetes 让云原生成为可能
- MCP 让 Agent 成为可能

每家公司从 2026 年起都需要 MCP 战略，等价于 Agent 战略。

OpenAI Agents SDK 支持 MCP 服务器工具；Claude Code 通过 MCP 扩展工具能力。

Anthropic 的 Managed Agent System 基于 MCP 为企业提供预配好的完整 Harness。
